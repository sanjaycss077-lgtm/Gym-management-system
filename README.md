# Gym Management System (Flask)

This is a web-based Gym Management System built using Flask to manage gym memberships and records.

## 🚀 Features
- Add and manage member details
- Store and organize data
- Simple and user-friendly interface

## 🛠 Technologies Used
- Python (Flask)
- HTML
- CSS
- JavaScript

## ⚙️ How to Run
1. Install requirements:
   pip install -r requirements.txt

2. Run app:
   python app.py

3. Open browser:
   http://127.0.0.1:5000/

## 📌 Purpose
Developed as part of academic learning to improve web development and data handling skills.
